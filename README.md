# 用户画像数据应用 · 高保真原型

钱坤股海通 / 综合业务管理平台（钱坤云）用户画像数据应用交互原型，覆盖两个场景：

- **业务中台用户画像查询平台**：按昵称 / 账号检索，展示用户信息、核心指标概览、圈子 / 课程和直播 / 软件特色三个维度的 12 项指标及偏好排名
- **企微侧边栏画像应用**：会话侧边栏内查看当前客户画像，默认收起、点击「用户画像」展开
